### 👋 About Me / Hakkımda

I am a **Software Developer** focused on bridging the gap between **native desktop/mobile ecosystems** and **modern full-stack web architectures**. I enjoy solving complex engineering challenges—from hardware-level input injection and real-time screen streaming over WebSockets to algorithmic matching systems backed by serverless PostgreSQL.

- 🔭 **Currently working on:** Cross-platform ecosystem tools (**macOS**, **iOS**, **Android**) & scalable full-stack web applications.
- ⚡ **Core Focus:** Low-latency networking (`WebSockets`, `Zeroconf/Bonjour`), Native UI (`SwiftUI`, `Jetpack Compose`, `PyQt6`), and Modern Web (`React 19`, `Node.js`, `PostgreSQL`).
- 🌍 **Philosophy:** Writing clean, maintainable, well-documented, and thoroughly tested code with a strong focus on end-user experience.
- 💬 **Ask me about:** Cross-device communication protocols, Full-Stack React & Express architectures, macOS Quartz/CoreGraphics APIs, and serverless deployments.
- 📫 **Reach me at:** [**ibrahimtemur847@gmail.com**](mailto:ibrahimtemur847@gmail.com) • [**linkedin.com/in/ibrahim-temur**](https://www.linkedin.com/in/ibrahim-temur)
